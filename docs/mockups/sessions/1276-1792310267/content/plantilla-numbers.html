A. Number field with a fixed "Plantilla" prefix

RSP types only the number (21, 13). New rows start empty, so nothing is guessed. The name always reads "Plantilla 21" for applicants, and digits only means no free-text slips.

B. Keep the free-text name, stop auto-numbering

This is the smallest change: the same field as today, but new rows start empty and focused instead of "Plantilla 3". RSP can still type any name, such as "Plantilla 21-A".

C. Type all the numbers at once

RSP types 21, 13 and so on in one box, and each number becomes a row. This is fastest for postings with many plantillas, but it adds a new control to the form.

In every option, applicants see "Plantilla 21" and "Plantilla 13", the numbers must be unique within the posting, and they can be changed later through Edit Posting.
