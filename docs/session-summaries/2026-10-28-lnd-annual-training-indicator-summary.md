# Annual training indicator — summary

## Shipped versus planned

- Added `getCurrentYearTrainingCounts` to `src/lib/api/lndArchive.ts`. It reads only the requested employees' Archive records, batches employee IDs, and paginates through all rows, including projects with a lower-than-requested server row cap.
- Completion year uses `to_date`, or `from_date` when the end is absent, in the Philippine calendar year through today. Missing, invalid, and future effective dates do not count. Shared enrollment links count once per employee.
- Recommendation rows now show `0/2 Completed this year`, `1/2 Completed this year`, etc. Actual totals remain visible above two. The requirement is a named constant, and the tooltip explains that these are recorded Archive completions.
- A pending read shows `Loading training count…`; a failed or incomplete read shows `Unavailable`, never an invented zero. Count responses are tied to their candidate snapshot and ignored after refresh/unmount when obsolete.
- The indicator appears only on the Recommendation subtab. No eligibility, sorting, acceptance, rejection, routing, roster, schema, or Archive-page behavior changed.
